## What is AI?

![[ai-dl-types.png|598]]

Here are somethings to remember about the ML/DL/AI jargon:

1. AI is not all about DL. 
2. DL and ML are both concerned fitting mathematical models to observed data.
3. Not all ML models are DL models.

## Supervised Learning

A simple definition of SL goes as follows:

> It is a mapping from input to some output.

Labeled inputs and outputs are provided at the time of learning.

![[sl-flow.png|658]]

If we want to learn the idea behind SL, a simple case would be learning how to predict the height of a child from weight.

![[Pasted image 20261013014715.png|650]]

The green line is just one curve that we learn during **training**, which is defined as follows:

> Searching through family of equations (family is a model) for an optimal fit of the data

In the kind of problem shown above, as the output is a continuous value it is called *regression* problem.

We can similarly describe the DL models as a:

> Very flexible family of equations.

## Regression

![[regression.png|826]]

**Univariate regression** is when we have just a single output.

We can even have regression for graph inputs (like a small molecule). These are called *graph regression* problems. And, a model can be made to predict more than one continuous output (like pH and boiling point), it then becomes **multi-variate regression**.

*Depth estimation* can be called a **multi-variate regression** problem. 

![[mvr.png|769]]

## Classification

![[classification.png|809]]

The problem shown above is a text input which gets classified based on the sentiment. If two discrete classes are possible outputs of the model (shown above) we get **binary classification model**. For more than two outputs, it becomes a **multi-class classification** model.

Inputs can be music, image etc.

An interesting case of classification problems involving images are **multi-variate binary classification** problems. These are also called *image segmentation* problems.

![[mvb.png|742]]

## Unsupervised Learning & Generative Models

![[rl-0.png|294]]

Translation, image captioning, image generation (based on text) and other such problems are different from what was discussed above. 

These tasks do not have a single correct output. The inputs have patterns, which are not easy to decipher. The model has to see many examples learn these rules.

1. There is a very complex relationship between the input and output.
2. There can be multiple "correct" answers.
3. Outputs & inputs may obey some rules (grammar).

Here the learning occurs from *unlabelled* examples. This happens through **unsupervised learning**.  Examples include:

- Clustering (DL models can also be used for clustering)
- Outliers
- Generating new examples
- Imputation

Conditional synthesis is an interesting kind of generative task, where model is asked to fill in the gaps:

![[cs.png|662]]


Models like GPT essentially are conditional synthesis models. Taking a prompt they generate the text!

## Reinforcement Learning

![[rl.png|446]]

Build an agent which lives in a world and can perform certain actions at each time step.

Example is a chess bot. States are valid chess board states.

![[rl-2.png|683]]

It is neither fully supervised, neither is it unsupervised as the agent learns from the outcomes.

This is generally a hard problem to solve in the real world due to the following reasons:

- Stochastic
	- opponent may or may not take a piece always for the same move
- Temporal credit assignment problem 
	- reward came from move at t=0 or t=now?
- Exploration-exploitation trade-off
	- should the agent always resort to known-good moves or explore new ones?

## Landmark papers

- 1958 Perceptron (simple "neural" model): Rosenblatt, [The perceptron: a probabilistic model for information storage and organization in the brain](https://doi.org/10.1037/h0042519)
- 1986 Backpropagation (practical deep neural networks): Rumelhart, Hinton & Williams, [Learning representations by back-propagating errors](https://doi.org/10.1038/323533a0)
- 1989 Convolutional networks (supervised learning): LeCun et al., [Backpropagation applied to handwritten zip code recognition](https://doi.org/10.1162/neco.1989.1.4.541)
- 2012 AlexNet image classification (supervised learning): Krizhevsky, Sutskever & Hinton, [ImageNet classification with deep convolutional neural networks](https://papers.nips.cc/paper/2012/hash/c399862d3b9d6b76c8436e924a68c45b-Abstract.html)
- 2014 Generative adversarial networks (unsupervised learning): Goodfellow et al., [Generative adversarial networks](https://arxiv.org/abs/1406.2661)
- 2014 Deep Q-learning, Atari games (reinforcement learning): Mnih et al., [Playing Atari with deep reinforcement learning](https://arxiv.org/abs/1312.5602), and the follow-up [Human-level control through deep reinforcement learning](https://doi.org/10.1038/nature14236)
- 2016 AlphaGo (reinforcement learning): Silver et al., [Mastering the game of Go with deep neural networks and tree search](https://doi.org/10.1038/nature16961)
- 2017 Machine translation (supervised learning): Vaswani et al., [Attention is all you need](https://arxiv.org/abs/1706.03762)
- 2019 Language models ((un)supervised learning): Radford et al., [Language models are unsupervised multitask learners](https://cdn.openai.com/better-language-models/language_models_are_unsupervised_multitask_learners.pdf) (GPT-2)
- 2022 DALL-E 2, image synthesis from text prompts: Ramesh et al., [Hierarchical text-conditional image generation with CLIP latents](https://arxiv.org/abs/2204.06125)
- 2022 ChatGPT: no paper, see the [announcement post](https://openai.com/index/chatgpt/) 
- 2023 GPT-4 multimodal model: [GPT-4 technical report](https://arxiv.org/abs/2303.08774)

Notice the gaps in the landmark papers, each gap marks a different paradigm.
